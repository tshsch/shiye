⬇️ 下载插件压缩包
安装步骤（Chrome / Edge 通用，约 1 分钟）
  1. 下载并解压上面的压缩包，得到一个 extension 文件夹
  2. Chrome 地址栏输入 chrome://extensions（Edge 输入 edge://extensions）
  3. 打开 「开发者模式」（Chrome 在右上角，Edge 在左侧栏）
  4. 点 「加载已解压的扩展程序」，选中刚解压的 extension 文件夹
  5. 浏览器工具栏出现拾页图标 → 点击图标登录你的拾页账号 → 之后任意网页一键收藏

· 手机浏览器暂不支持浏览器插件，手机上用网页端粘贴收藏即可
· 插件与网页登录的是同一账号，收藏内容实时同步
