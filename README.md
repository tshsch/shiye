# 拾页 —— 三分钟跑起来

## 启动（答辩电脑上也一样）
1. 双击 `启动拾页.bat`，浏览器会自动打开 http://localhost:3000
2. 完成。无需安装任何东西。

## 开启 AI 能力（强烈建议）
1. 到 platform.deepseek.com 注册，创建 API key（充 10 块钱够比赛用）
2. 复制 `.env.example` 改名为 `.env`，把 key 填进去
3. 重新双击 `启动拾页.bat`

没有 key 也能跑（演示模式）：预置了 5 篇文章、收藏夹、书架、广场评论，问答返回检索结果。

## 现场演示动线
1. 「收藏夹」页：粘贴一篇公众号文章链接 → AI 10 秒生成导读卡 + 标签
2. 打开文章详情 → 挂到《置身事内》下 → 切到「书架」看聚合
3. 「问收藏」页：问"我的收藏里是怎么讲土地财政的？" → 带出处的回答
4. 「广场」页：展示同学的推荐和讨论
