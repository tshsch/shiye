# 拾页 · 使用说明

> 收藏了却没读？拾页帮你把随手存下的东西真正读懂、用上。
>
> 粘一个链接，它给你一张导读卡；你正在读哪本书，它把相关文章按书归在一起；想不起来某件事在哪篇看过的，直接问它，它只从你自己的收藏里找答案，还标出出处。

---

## 一分钟上手

1. 双击 **`启动拾页.bat`**
2. 浏览器会自动打开 <http://localhost:3000>，看到「拾页」的页面就成功了
3. 第一次用，点右上角注册一个账号（用户名 2–20 位中文/字母/数字，密码至少 4 位）
4. 想先随便逛逛，可以用演示账号：**`demo` / `demo123`**（里面预置了 5 篇文章、书架和广场评论）

不需要安装任何东西，不需要命令行，关掉黑色窗口就停止服务，再双击就又起来了。

---

## 五个页面，分别是干什么的

| 页面 | 用法 |
| --- | --- |
| **今日** | 每天一份阅读计划：挑 3–5 篇你存了没读的，凑够你设定的时长，还告诉你为什么今天读它 |
| **收藏夹** | 你所有的收藏。可以按文件夹筛、按关键词搜 |
| **书架** | 按「书」聚合资料。读《置身事内》时看到的相关文章，都挂在同一本书下面 |
| **广场** | 同学们公开推荐的文章。推荐时必须写一句理由，评论可以点赞、可以收藏 |
| **问收藏** | 用大白话提问，它只从你自己的收藏里找答案，每句话后面带编号，点编号跳回原文 |

## 怎么收一篇文章

### 方式一：粘链接（最常用）

在页面顶部输入框粘贴文章链接，点「收进来」。微信公众号、知乎、普通网页都行。

它会自动做四件事：抓出正文、去掉广告和导航、生成摘要与标签、判断该归到哪个文件夹或哪本书下。几秒钟后会弹出一张卡片告诉你它做了什么。

### 方式二：直接粘正文

有些网站有登录墙或者反爬，抓不到正文。这时把文章内容复制下来，粘到输入框下面那个大文本框里，一样能收。

### 方式三：浏览器插件（一键收藏任意网页）

1. 页面顶部导航点「插件」，下载压缩包并解压，得到一个 `extension` 文件夹
2. Chrome 地址栏输入 `chrome://extensions`（Edge 输入 `edge://extensions`）
3. 打开右上角的「开发者模式」
4. 点「加载已解压的扩展程序」，选中刚才那个文件夹
5. 浏览器工具栏出现拾页图标，点它就能把当前网页收进来

> 插件只是更顺手的入口。**不装插件，网页端粘贴一样能完成全部操作**，手机上也能用。
> 如果插件提示没登录，先在网页端登录一次，再回头点插件。

## 四个最值得试的功能

### 1. 让 AI 自己整理

收进来之后，它会看一眼你的文件夹和书架，自己判断这篇该放哪：能挂到某本书就挂上，需要新文件夹就建一个，标签不准就顺手改掉。卡片上会写一句它干了什么。

**不满意可以随时改。** 文章详情里能自己换文件夹、换书、改标签。想让它重新判断一次，点「重新整理」。

### 2. 按书聚合

一本书就是一个资料库，不是一个文件夹。

建书的时候直接输书名就行，带不带书名号、有没有副标题、用的是哪个译名，它都会帮你归到同一本。输了「课程名」或者「文章标题」这种不是书的，它会提醒你换一个。

### 3. 问收藏

用你平时说话的方式问，比如：

- 我收藏里是怎么讲土地财政的？
- 番茄工作法适合什么样的人？
- 有没有讲论文怎么写引言的？

它会在你自己的收藏里翻几轮，找到最相关的段落再回答，每句话后面标 `[1] [2]`，点一下就能跳回原文那一段。

**收藏里没有的，它不会编。** 会直接告诉你「你的收藏库里暂时没有和这个问题相关的内容」。

### 4. 每日策展

「今日」页面每天给你排一份计划：几篇、几分钟、按什么主题、为什么是这几篇。

它会看你的积压、最近在读什么、书架进度、昨天推了你看没看，再决定今天怎么安排。觉得不对，点重新生成。

在个人主页里可以改每天的阅读预算（5–60 分钟），它就按这个时长来配。

## 常见问题

**Q：一定要联网吗？**
要。服务跑在你自己的电脑上，但 AI 功能需要访问网络。

**Q：没有 AI 也能用吗？**
能。没有配置 AI 时是「演示模式」：预置了文章和评论，收藏时会用本地规则生成摘要和标签，问答会返回最相关的几段原文。想开完整 AI 能力，见下一节。

**Q：收藏的内容别人能看到吗？**
默认看不到。只有你把文件夹设成公开，或者在广场推荐时写了推荐语，别人才能看到那部分内容。

**Q：删除会不会删错？**
不会手一抖就没了。点删除按钮后它会变成「确认删除」，2.5 秒内再点一次才真正执行。删掉的包括文章正文、段落和它下面的评论。

**Q：手机上能用吗？**
浏览器打开同一个地址就能用。插件只支持电脑浏览器。

**Q：忘记密码了？**
目前没有找回功能。可以重新注册一个账号。

## 想打开完整 AI 能力（可选）

不配置也能用，只是效果会弱一些。配置只需三步：

1. 到 <https://platform.deepseek.com> 注册，创建一个 API key（充少量余额就够用很久）
2. 把项目里的 `.env.example` 复制一份，重命名为 `.env`，把 key 填进去：

   ```
   LLM_API_KEY=sk-你的key
   LLM_BASE_URL=https://api.deepseek.com
   LLM_MODEL=deepseek-chat
   ```

3. 关掉黑窗口，重新双击 `启动拾页.bat`

启动时窗口里会显示 `AI 能力: 已连接 (deepseek-chat)`，页面右上角的徽标也会变成已连接状态。

> 也支持其他兼容 OpenAI 接口的模型服务，改 `LLM_BASE_URL` 和 `LLM_MODEL` 即可。
> `.env` 里是你的私人密钥，**不要发给别人，也不要上传到公开仓库**。

## 数据存在哪

所有收藏、账号、评论都在项目目录下的一个文件里：**`data.db`**。

- 想备份，复制这个文件就行
- 想整个重置，关掉服务，删掉 `data.db` 和同目录下的 `data.db-wal`、`data.db-shm`，再启动就会重新生成
- 换电脑，把整个文件夹复制过去就能接着用

## 遇到问题

**双击后窗口一闪就没了**
可能是 3000 端口被占用。先关掉其他正在跑的程序再试，或者改 `.env` 里加一行 `PORT=3001` 换个端口。

**页面打开是空白的**
在窗口里按 `Ctrl+C` 停掉，重新双击启动。浏览器按 `Ctrl+F5` 强制刷新一次。

**一直显示「AI 未连接」**
检查 `.env` 文件名是否真的叫 `.env`（不是 `.env.txt`），key 前后不要有空格，改完必须重启服务。

**收藏时提示「该网页抓取失败」**
这个网站不让程序抓取正文。把文章内容复制下来，粘到页面上的正文输入框里，一样能收。

**问收藏说找不到**
换个说法再问，或者先多收几篇。它只在你已有的收藏里找，不会上网查。
